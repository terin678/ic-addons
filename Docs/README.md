# Docs

One guide per addon, written for the player who installs it, plus shared references for
maintainers.

| Document | What it covers |
| --- | --- |
| [MalexisAuctionWatcher.md](MalexisAuctionWatcher.md) | Installing and using the auction watcher: tracking, scanning, history charts, recipes, external sources |
| [AuctionatorSellingTweaks.md](AuctionatorSellingTweaks.md) | Companion addon: Expiry column and narrower "You?" in Auctionator's Selling price list |
| [CutMaster.md](CutMaster.md) | Jewelcrafting book scanning, trade chat/whisper customer detection, order tracking, income |
| [TradeMaster.md](TradeMaster.md) | Crafting business assistant for any profession: scanning, customers, barking, orders, income |
| [ICLibs.md](ICLibs.md) | Shared library addon: LibICTradeSkill reads profession windows into books, LibICUI is the window and list toolkit |
| [GuildRecruitment.md](GuildRecruitment.md) | One recruitment message the raid leaders set and every officer sends, kept in step across the guild, with a log of who barked when |
| [ICTemplate.md](ICTemplate.md) | The worked example: a live gallery of every LibICUI widget, and the folder you copy to start a new addon |
| [client-reference.md](client-reference.md) | Interface versions, client folders, and API notes per flavor |

Guides first, shared references last. When you add an addon, add its guide here and link it
from the root README table — `scripts/new-addon.ps1` does both for you.
